Kostenlose Code-Signierung durch SignPath.io, Zertifikat von der SignPath Foundation.

1. Was signiert wird

Die Windows-Installer (…_x64-setup.exe und …_x64_*.msi) auf der Release-Seite bei GitHub. GitHub Actions baut sie direkt aus dem markierten Quellcode im öffentlichen Repository wheatley2056/twogg-pinecone (Workflow .github/workflows/release.yml). Nichts wird auf einem privaten Rechner gebaut oder signiert.

Signiert wird nur Software aus diesem Repository, niemals Programme Dritter.

2. Rollen im Team

  • Committer und Reviewer: Mitglieder des Repositorys. Beiträge von außen kommen nur nach Prüfung über einen Pull Request hinein.
  • Freigabe: Tobias Kern (wheatley2056). Jede Signieranfrage für ein Release wird von Hand freigegeben.

Alle im Team nutzen Zwei-Faktor-Anmeldung bei GitHub und SignPath.

3. Datenschutz

Dieses Programm überträgt keine Informationen an andere Systeme im Netz, außer der Nutzer oder die Person, die es installiert oder betreibt, verlangt es ausdrücklich. Pinecone verbindet sich nur für das, was du nutzt: Microsoft und Mojang für die Anmeldung und den Download von Minecraft, Modrinth und den Pinecone-Server für Mods, Modpacks, Neuigkeiten und die Freundesliste, twogg.app für den Event-Kalender und, wenn du dein TwoGG-Konto verknüpfst, deine Anmeldungen, sowie GitHub, um nach neuen Versionen zu sehen. Es gibt kein Tracking und keine Analyse. Einzelheiten stehen in der Datenschutzerklärung.

4. Meldungen

Findest du eine signierte Datei, die nicht aus diesem Projekt stammt, oder hast du andere Bedenken zur Signierung, schreib an legal@twogg.de.
